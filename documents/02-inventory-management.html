A1. Types of Paper Packaging in the Market

Paper arrives from mills and is sold to customers in different physical forms. A robust inventory system must track all packing types simultaneously, since each has its own unit of measure and stacking/storage behaviour.

📦 Cut Sheets
Paper cut to standard sizes, bundled together
  • Packed in reams (standard: 500 sheets)
  • Multiple reams wrapped in a packet/bundle
  • Typically: 50–500 reams per pallet/lot
  • Common sizes: 23×36″, 22×34″, 24×36″, 20×30″
  • Used for: printing, packaging boards, FBB, duplex
Units: Sheets / Reams / Packets
🎡 Reels / Rolls
Continuous paper wound onto a core
  • Measured primarily in KG or MT
  • Width defined by mill reel width (cm/mm)
  • Used for: newsprint, tissue, kraft, writing paper
  • Can be full-width (parent reel) or slit reels
  • Stored vertically or horizontally on racks
Units: KG / MT / Rolls
📋 Boards / Thick Sheets
High-GSM boards, carton boards, packaging boards
  • Supplied as individual large sheets
  • Counted in number of sheets or by weight
  • GSM range: 150 – 600+ GSM
  • Types: FBB, White Back, Grey Back, Duplex, SBS
  • Usually palletized with specific sheet-count per pallet
Units: Sheets / KG
📬 Packets / Bundles
Pre-packed units for easy handling
  • A set number of sheets pre-wrapped (e.g., 100 or 250 sheets)
  • Mostly used for copier paper, bond paper
  • A-4, Letter, Legal sizes common
  • Sold by box (5 reams = 1 box typically)
  • Inventory tracked in packets or boxes
Units: Packets / Boxes / Reams

A2. Units of Measurement in Paper Trading

Paper is one of the few commodities traded simultaneously in multiple units — the same material may be purchased from a mill in KG, sold to a customer in sheets, and stored in reams. The inventory system must handle all unit types and conversions between them.

UnitAbbreviationUsed ForConversion Reference
SheetShtsCut sheets, boards — primary stock unit for countingBase unit; 1 ream = 500 sheets (standard)
ReamRmBundled cut sheets in multiples of 5001 ream = 500 sheets
Packet / BundlePktPre-packed units of 100, 250 or 500 sheetsPacket size defined per material in master
Box / CartonBoxCopier paper, A-4 paper, retail packing1 box = typically 5 reams = 2500 sheets
KilogramKGReels, kraft paper, newsprintKG = (Sheets × GSM × Area in m²) / 1000
Metric TonMTBulk procurement, freight billing1 MT = 1000 KG
RollRollReel count (when each reel is a unit)1 roll weight varies by width/diameter
Weight Calculation Formula:
Weight (KG) = (Number of Sheets × GSM × Sheet Area in m²) / 1000
Example: 10,000 sheets of 300 GSM, 23″×36″ = 10,000 × 300 × (0.5842×0.9144) / 1000 ≈ 1,604 KG

A4. Inventory Data Structure & Fields

The core inventory record (called a Stock Lot in Monit ERP) must capture all data needed to track material through its full lifecycle — from receipt to dispatch. Below are the universal fields required for any paper trading inventory system.

FieldTypePurpose
lot_id / batch_idString (unique)Primary identifier for this stock lot
lot_numberString (auto)Human-readable lot reference (e.g. LOT-2026-001)
material_idFK → Material MasterWhat paper type this lot contains — links to GSM, size, type
mill / supplier_idFK → Mill MasterSource mill from which this lot was received
received_dateDateCritical for FIFO — oldest date dispatched first
grn_numberFK → GRNLinks to the receipt document that created this lot
warehouse_idFK → WarehousePhysical warehouse where lot resides
bin_locationFK → Bin MasterExact physical storage bin for pick planning
received_qtyNumberOriginal quantity received — immutable after creation
current_qtyNumberPhysical quantity still in stock (decreases on dispatch)
allocated_qtyNumberQuantity soft-reserved against confirmed SOs
available_qtyNumber (computed)= current_qty − allocated_qty (free to allocate)
unitEnumSheets / KG / Reams / Packets — per material setting
quality_gradeEnumA Grade / B Grade / Damaged — set during QC inspection
statusEnumAvailable / Allocated / Partially Dispatched / Depleted
batch_tagString (optional)Mill batch or lot identification from mill's own system
purchase_rateDecimalRate at which this lot was procured (for stock valuation)
stock_valueDecimal (computed)= current_qty × purchase_rate
expiry_dateDate (optional)For specialty papers with shelf life limits
notesTextAny quality observations, handling instructions
Key Design Principle: The available_qty is always a computed value, never stored independently. It is derived as current_qty − allocated_qty. This prevents data inconsistency — only current_qty and allocated_qty are mutated by business operations.

B1. Inventory Architecture in Monit ERP

Monit ERP manages inventory across 3 warehouses (Lasudia, Sanwer, Pithampur) with bin-level tracking. The inventory state is managed through a shared StockContext — a React Context that maintains all StockLots and GRNs in memory, with mutations exposed as typed functions callable by any page.

ComponentRole in Inventory
StockContextCentral state manager — holds all StockLots and GRNs; exposes addToStock(), allocateLot(), deallocateLot(), dispatchLot(), getAvailableByMaterial()
GRN PageInbound entry point — manages quality inspection workflow; triggers addToStock() to create StockLot on final approval
Stock Lots PageReal-time inventory ledger — reads directly from StockContext; shows all lots with qty states and bin locations
Coverage PageUses StockContext.getAvailableByMaterial(materialId) to compare available stock vs. SO requirements
Pick Plan PageReads StockContext.getLotsByMaterial(materialId) sorted by receivedDate (FIFO); calls allocateLot() to reserve stock
Challan PageOn dispatch confirmation, calls StockContext.dispatchLot() to permanently reduce currentQty

Two-Phase Deduction: allocateLot() is a soft reservation — material is still physically in the warehouse. dispatchLot() is the hard deduction — material is confirmed loaded on a truck. This separation means the system accurately reflects both "what is reserved" and "what has physically left".

Deallocation (Cancellation / Reduction)

If a SO is cancelled or its quantity is reduced after allocation, the system calls deallocateLot(lotId, qty) which reduces allocatedQty and restores the corresponding availableQty — making that stock freely available to other orders without any physical movement.

B4. FIFO Allocation Logic

FIFO (First In, First Out) is the primary stock allocation strategy in Monit ERP. When paper is needed for a sales order or dispatch, the system always selects the oldest received lot first — regardless of bin location. This minimizes stock ageing and ensures older material is consumed before newer arrivals.

FIFO Example — Allocating 15,000 Sheets of FBB 300 GSM 23×36

Lot NumberReceived DateAvailable QtyFIFO OrderAllocated This Run
LOT-2024-00110-Jan-20242,000① OLDEST — pick first2,000 (exhausted)
LOT-2024-00520-Jan-202412,000② Second oldest12,000 (partially used)
LOT-2024-01028-Jan-202420,000③ Newest — pick last1,000 (remaining 1K needed)
Total Allocated: 2,000 + 12,000 + 1,000 = 15,000 Sheets ✅
getLotsByMaterial(materialId): → Filter: lots where materialId matches AND status ≠ "Depleted" → Sort: receivedDate ASC // oldest first = FIFO order → Return: sorted lot array allocateForSO(materialId, requiredQty): remaining = requiredQty lots = getLotsByMaterial(materialId) FOR each lot IN lots: toAllocate = MIN(lot.availableQty, remaining) allocateLot(lot.id, toAllocate) // reserve from this lot remaining -= toAllocate IF remaining == 0: BREAK // fully covered IF remaining > 0: RAISE shortage // not enough stock

Why FIFO Matters for Paper Trading

  • Quality preservation: Paper stored too long may develop moisture issues, yellowing, or edge damage — consuming older stock first reduces waste
  • Accurate cost matching: FIFO ensures cost of goods sold reflects older (often lower) purchase rates, providing cleaner financial reporting
  • Mill claim tracking: If a batch from a specific mill has quality issues, older lots are consumed first, reducing exposure time
  • Compliance: Most paper trading businesses follow FIFO as a standard accounting and stock management practice

B5. Warehouse & Bin Location Management

Monit ERP tracks stock at bin level — the smallest physical unit of storage (a single shelf position). This enables accurate pick planning and eliminates warehouse search time during dispatch.

GRN Bin Assignment

When a GRN is created, the system suggests a bin based on material type and available space. The planner can accept the suggestion or override to a different bin before finalizing the Stock Updated step. The assigned bin is stored with the Stock Lot and used by Pick Plan.

Bin Occupancy Tracking

As material is added to a bin (via GRN → Stock Lot), the bin's current occupancy increases. As material is dispatched (via Challan), occupancy decreases. The Bin Location Master always reflects current occupancy, enabling the GRN suggestion engine to identify available bins.

B6. Coverage Calculation & Gap Analysis

Coverage is the real-time snapshot of supply vs. demand for each material across all confirmed Sales Orders.

COVERAGE ANALYSIS per Material: Physical Stock = SUM(availableQty) across all StockLots with matching materialId In-Transit Stock = SUM(ordered qty) from confirmed POs not yet received (GRN pending) SO Requirement = SUM(required qty) across all confirmed, non-dispatched SO lines COVERAGE = Physical Stock + In-Transit Stock − SO Requirement IF Coverage > 0 → SURPLUS → Allocate to SO(s), no procurement needed IF Coverage == 0 → EXACT → Allocate all available stock IF Coverage < 0 → SHORTAGE → Raise Purchase Order for the deficit quantity

Coverage Decision Matrix

Coverage ResultSystem RecommendationAction
Surplus (+ve)Stock available; allocate to SORun Pick Plan from existing stock
Exact (zero)Stock barely sufficientAllocate all; flag for monitoring
Shortage (−ve)Stock insufficientRaise PO for deficit qty (Against SO or For Stock)
In-Transit Visibility: POs that have been confirmed by mills (status: "Mill Confirmed" or "Dispatched from Mill") count as in-transit stock in the coverage calculation. This prevents unnecessary re-procurement when material is already on its way to the godown.
